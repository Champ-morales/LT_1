## Description

This program calculates the total boxes received and how many boxes can be packed, and shows how many notebooks will go to a loose pack.

## How to Run

1. Open the program file in VS Code, Replit, or Google Colab.

2. Run the program.

3. Enter the values for notebooks_total, notebooks_per_box

4. Check the result displayed on the screen.

## Input Needed

- notebooks_total

- notebooks_per_box


## Sample Output

How many notebooks total: 200

How many notebooks per box: 15

There will be 13 full boxes and 5 notebook/s go in a loose pack.
